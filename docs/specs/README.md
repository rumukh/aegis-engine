# Specifications

`aegis-extension-spec.md` is the **canonical copy** of the AEGIS extension specification
(v1.3, including section 22 Witch Kitchen and section 23 Fluffy Bureau). It was imported
byte-for-byte from `rumukh/fluffy-bureau` branch `rumukh-game-feasibility-assessment`
on 2026-10-08. From that date, changes to the specification are made here, through a
pull request against this repository, with a dated entry below and a versioned note to
every consumer workstream.

The file is excluded from formatting so that its bytes stay comparable with the source
it was imported from.
